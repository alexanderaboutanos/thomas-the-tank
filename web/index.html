A toy real-time telemetry board for the engines of the North Western Railway — a hands-on playground for a streaming data pipeline, dressed up as a locomotive cab.

Pull the master regulator and each engine starts reporting in. Two paths carry the data:

  • Live view — Confluent Cloud → Kafka tap → Server-Sent Events → this page, streaming each fresh reading as it lands.
  • Analytics — the same events sink to Snowflake, where canned queries roll them up on demand.

Everything is served same-origin: CloudFront fronts the static page (S3) and proxies /stream, /produce and /query to an always-on live-tap container on ECS — no API keys, no CORS, no mixed content. Toot toot!
